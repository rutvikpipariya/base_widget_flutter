# base_widget_flutter example

A three-tab showcase of the package:

- **Overlay**: `BaseWidget` with `isLoading`, `loadingMessage`, `loadingBlur`, `canPop` and `dismissKeyboardOnTap`.
- **States**: `BaseStateView` switching between loading, empty, error and content, with pull-to-refresh.
- **Styles**: `BaseTextStyles` weights and `HexColor` parsing.

```sh
cd example
flutter create . --platforms=android,ios   # first time only
flutter run
```
